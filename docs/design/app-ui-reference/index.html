두 차례 검토와 남은 확인

캡처에서 작성 버튼이 아래로 밀리고 읽는 쪽지 옆에 다른 행동이 경쟁하는 문제를 확인했습니다. 작은 위치 사진과 고정된 완료 행, 선택한 흔적만 남기는 읽기 상태로 수정했습니다.

2차 화면 검토 · 큰 글자와 실패

긴 글의 본문만 스크롤해 닫기·추천을 유지했습니다. 너비 360/390/430과 글자 100/200%, 복귀·입력 보존·사진 오류 복구를 포함한 15개 HTML 검사를 통과했습니다.
