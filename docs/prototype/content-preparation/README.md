# P01 자료 묶음 — 비교 후보·관련 질문·다음 관람

자료 버전: `2026-10-16-p01.1`. 이 폴더는 P01 당시의 준비 자료다. P02에서 [런타임 content.json](../content/content.json) v2에 실제 자료를 병합했다. 이 packet은 부분 변경 입력이므로 런타임 Dataset으로 쓰지 않는다. 아래 이관 절차·검수 기록은 P01 시점의 근거이며 최신 실행·검증은 [앱 안내](../../../prototype/README.md)를 따른다. P01 기록의 원본은 [기존 Issue](https://github.com/HyunKN/visual-travel-guide/issues/6)다.

2026-10-16 각 제공 화면과 원본 파일을 확인했다. 세 파일 모두 공공누리 제1유형 표시가 있는 자료이며 [유형 안내](https://www.kogl.or.kr/info/licenseType1.do)에 따라 제공기관·제목·원문·이용 조건을 표시한다. 개별 촬영자 이름은 확인하지 못해 제공기관으로 표기했다. 상품 이미지나 굿즈 사진은 사용하지 않았다.

원본 바이트를 그대로 저장했고 실제 JPEG 크기·용량·SHA-256은 packet의 Asset에 기록했다. 크롭·보정·생성형 확대는 하지 않았다. 정확한 촬영일은 모두 미상이다. 포털 파일명에 있는 2021 날짜와 페이지 갱신일을 촬영일로 바꾸지 않는다. 최근 촬영일이 입증된 사진이라고 소개하지 않는다.

이 자료 3장의 원본 합계는 12,395,147 bytes다. 현재 앱의 publicDir 밖에 두어 기존 빌드에 추가하지 않았다. P06에서 화면용 크기·포맷·로딩을 결정할 때 원본·파생본의 해시와 변경 내용을 구분한다. 이 원본을 모두 초기 로딩하라는 명세가 아니다.

### 사진에서 확인한 것과 한계

- 사정전·수정전은 단층·기와·단청 전각이라는 공통점이 있어 모사 비교 대상으로 선정했다. 실제 방문객의 혼동 빈도나 AI의 혼동률을 측정한 결과는 아니다.
- [사정전 해설](https://encykorea.aks.ac.kr/Article/E0002445)의 정면 5칸과 [수정전 해설](https://encykorea.aks.ac.kr/Article/E0002446)의 정면 10칸을 구별 단서로 사용한다. ‘칸’은 기둥 사이 공간이다. 관찰 성공에 정확한 칸수 세기를 요구하지 않고 문·기둥 배열과 전체 폭을 대조했는지 본다.
- 수정전은 나무가 일부 문을 가리고 사정전은 앞쪽 문의 기둥이 양옆을 가린다. 작은 현판을 읽거나 가려진 기둥 수를 추측하도록 만들지 않는다. 현판 독해·배경/계절·같은 사진 기억으로 골랐으면 그 이유도 기록한다.
- 320 CSS px 정적 검수 화면에서 원본 3장과 문구 줄바꿈·정면 폭 차이를 육안 확인했다. 실제 후보 화면 C·터치·기기 회전·확대는 P06/P07 검사다. 사람의 구별 성공은 P08 전에는 미검증이다.
- 궁능유적본부 사정전 5693·수정전 5704 항공 전경은 건물이 작고 여러 동이 보여 후보 비교에 채택하지 않았다. 원문 열람만으로 모든 사진이 같은 구도·품질이라고 가정하지 않았다.

## 통합 계약

packet은 완성된 v2 Dataset이 아니라 **기존 v1에 합칠 추가 자료와 변경안**이다. 기존 JSON을 이 파일로 통째로 교체하면 안 된다.

1. `baseContentVersion`이 현재 콘텐츠와 같은지 확인한다. 다르면 다른 변경과 먼저 대조한다.
2. sources/assets/scenes/targets/questions/answers를 ID 중복 없이 추가한다. packet의 assets 경로는 P06 통합 뒤 publicDir 기준이다. 현재 실물은 이 폴더의 assets다.
3. `targetQuestionUpdates`의 기존 floor/panel에 질문을 덧붙이고 기존 질문은 유지한다.
4. P02에서 schemaVersion 2와 comparisonCases·continuations·navigationScenes 검사를 구현한 뒤 실제 데이터를 함께 이관한다. 현재 v1 앱에는 넣지 않는다.
5. 기존 장면은 보존한다. 새 C04는 입력, C05/C06은 각 후보 참고 장면이다. C04에 틀린 후보 사정전을 실제 target으로 넣지 않는다.
6. 후보 과업 전에 N·추천으로 C04~C06을 보여주지 않는다. S1→S2→S3→S4 이후 S5에서 다음 관람 연결을 관찰한다. S5는 새로운 제품 기능이 아닌 동일 흐름의 별도 테스트 preset이다.
7. 통합 시 총 6장면·7대상·13답변·6질문·6사진이 된다. 실제 schemaVersion 2 검사와 브라우저 확인은 P02/P06의 결과로 남긴다.

P01은 사진·해설·질문·연결과 진행자 자료를 준비하는 범위다. 실제 UI 구현·사용자 최종 콘텐츠 확인·실기기·사람 관찰을 대신하지 않는다. 작성한 묶음은 로컬 자료이며 커밋·푸시·Wiki 게시 여부는 실제 수행 기록으로 따로 확인한다.
