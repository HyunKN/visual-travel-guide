# P01 진행자용 정답·순서

자료 버전 `2026-10-16-p01.1`. 이 문서는 현재 Vite publicDir 밖의 진행자 자료다. 참여자가 조작하는 화면에 정답표를 넣거나 시작 전에 읽어주지 않는다. 정답 은닉은 보안 기능이 아니다.

## 시작 전

- 준비된 사진·결과를 사용하는 프로토타입이며 실제 인식·GPS·자유 질문 답변이 없다고 안내한다.
- 앱/contentVersion·기기·상황 순서·후보 순서를 기록한다. 아래 순서는 P02/P06이 해당 preset과 화면을 구현한 뒤 시행할 안이다.
- 지원 영역 밖에 관심을 보이는 것과 조작 실패를 구분한다. 답변이 준비되지 않으면 즉석 검색·설명으로 과업 성공을 만들지 않는다.

## 상황 순서와 사전 노출 방지

| 순서 | 상황 | 노출 조건 |
| --- | --- | --- |
| 1 | S1 경회루 전체 설명 | 기존 C01. C04~C06과 다음 수정전 제안은 노출하지 않음 |
| 2 | S2 근정전·앞마당 부분 | 의도·궁금증을 먼저 듣고 자발적/지정 과업을 구분 |
| 3 | S3 십장생굴뚝 홈 카드 | 앞에서 굴뚝 해설을 미리 제공하지 않음. 무시도 유효한 결과 |
| 4 | S4 건물 후보 비교 | 입력 C04·후보 A 사정전 C05 / B 수정전 C06. 앞선 N·카드에서 이 사진들을 노출하지 않음 |
| 5 | S5 설명 이후 다음 탐색 | 경회루 설명에서 수정전 제안, 다른 대상 알아보기. 이미 본 대상이므로 최초 발견 효과로 해석하지 않음 |

S5에서도 먼저 행동을 기다리고 필요하면 ‘이제 무엇을 하려고 하나요?’로 의도를 묻는다. 다른 대상으로 가도록 지시하는 보조 과업은 자발적 행동 관찰을 마친 뒤 별도로 기록한다. 설계에 없는 자유 촬영이나 임의 질문 해결 과제를 만들지 않는다.

## S4 정답과 판단 기준

- 입력 파일: `assets/sujeongjeon-input.jpg`, 궁능유적본부 파일 5705.
- 실제 대상: **수정전**. 고정 순서에서 후보 B / `option-sujeongjeon` / 참고 장면 C06.
- 후보 A: 사정전, `option-sajeongjeon` / 참고 장면 C05.
- 의도한 구별 단서: 정면 문·기둥이 가로로 길게 이어지는 모습. 공식 해설의 정면 칸수는 사정전 5칸, 수정전 10칸이다.
- 사진의 나무가 일부를 가리므로 정확히 열 칸을 세도록 요구하지 않는다. 작은 현판을 읽거나 사진 속 소나무·배경·계절·색만 보고 골랐으면 그 선택 이유를 그대로 기록한다.
- 오답은 자동 교정하지 않는다. 설명을 읽은 뒤 후보 재비교로 돌아가는지 확인할 수 있지만 정답 방향을 지시하지 않는다.
- ‘둘 다 아닌 것 같아요’를 고르면 입력 사진과 준비된 후보의 불일치라고 느낀 이유를 듣는다. 같은 사진을 기억하고 선택한 것과 형태·근거 비교를 구분한다.
- 정답 여부와 확신·선택 이유를 따로 적는다. 정답을 골랐다는 이유만으로 비교 단서를 이해했다고 판정하지 않는다.

## 관련 질문을 관찰할 때

1. 설명·질문 목록을 보여주기 전에 어떤 대상에서 무엇이 궁금한지 듣는다.
2. 기본 설명과 준비된 질문을 자유롭게 이용하게 한다. 질문을 반드시 누르라고 하지 않는다.
3. 설명 후 ‘원래 알고 싶었던 내용에 답이 됐나요?’, ‘남은 궁금증이 있나요?’를 묻는다.
4. 질문 0개인 근정전 전체·연기 배출구에서는 빈 상태를 이해하고 기본 설명·다른 부분·새 탐색으로 돌아갈 수 있는지 본다.
5. 준비된 질문 밖의 궁금증은 익명 요약한다. 기록은 콘텐츠 보강·범위 판단 자료이며 자유 질문/LLM 필요성이 확정된 증거가 아니다.
