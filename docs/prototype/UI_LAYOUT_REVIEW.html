사진 선택 다음 화면의 배치

전체·부분 선택: 상단 뒤로 / 제목 / 검색 → 선택한 사진(전체가 보이게, 확대 가능) → 고른 부분의 미리보기·확인 → 건물 전체 알아보기 → 글로 대상 고르기. 하단 이동은 유지한다. 아직 아무것도 고르지 않았다면 정답 표시를 미리 그리지 않는다.

후보 확인: 상단 뒤로 / 제목 / 검색 → 알아보는 사진 → 후보별 참고 사진·이름·구별 근거·선택 → 둘 다 아닌 것 같아요 / 사진 다시 보기. 선택 후에도 뒤로 또는 후보 재비교로 수정한다. 후보가 필요한 사진에서만 보이며, 일반 탐색을 가로막지 않는다.

위 두 화면의 세부 시안은 이 4개 기본 화면의 배치 검토에 맞춰 함께 다듬는다. 아직 확정된 명세가 아니다.

먼저 검토받을 배치와 이동 규칙

  1. 홈 상단 검색창: 건물 이름·문양·바닥 같은 단어로 준비된 자료를 찾는다. 카메라 아이콘은 사진 탐색으로 간다.
  2. 주 탐색 80 : 보조 호기심 20: 공통 헤더·하단 이동을 제외한 첫 화면 콘텐츠의 대략적인 비중이다. ‘잠깐, 이런 것도 있어요’는 작은 제목·88×88px 사진·14px 문구의 가로 구성으로 줄이고 전체 높이는 약 130px를 목표로 한다. 글자가 커지거나 문구가 길어지면 높이는 자연스럽게 늘린다. 비율을 맞추려고 텍스트를 자르지 않는다.
  3. 하단 세 입구: 홈 / 검색 / 사진으로 찾기. 모든 주요 화면에서 유지하고 작은 화면에서도 조작부를 가리지 않게 배치한다. 이 세 개가 중복되거나 복잡한지는 검토받는다.
  4. 뒤로가기: 검색에서 열었으면 검색 결과로, 사진에서 열었으면 사진 선택으로 돌아간다. 설명에서 갑자기 홈으로 보내지 않는다. 뒤로 갈 화면이 없는 직접 진입은 홈으로 안전하게 연결한다.
  5. 기존 홈 디자인: 사진형 홈을 위에 표시했다. 3D형도 같은 검색창·하단 이동을 사용하고 대표 사진 자리만 궁궐 이야기로 바꾼다. 승인 전 새 3D·유리 효과를 구현하지 않는다.
  6. 설명 이후: 같은 사진의 다른 부분 / 새 검색·사진 탐색 / 다음 관람 제안을 선택한다. 지원 부분이 없는 사진에는 ‘다른 부분 보기’를 숨긴다.
  7. 시나리오: 같은 앱에서 건물 찾기 → 부분 탐색 → 호기심 카드 → 후보 확인 → 다음 탐색 과제를 순서대로 관찰한다. 과제 순서가 앱의 사진·기능·이동을 잠그지 않는다. 사전 노출이 있었다면 관찰 기록에 남긴다.

이 문서는 배치 검토 기록이다. 현재 앱은 자유 탐색·준비된 자료 검색·스포카 한 산스를 적용하며 실제 사용성 관찰은 별도로 진행한다.

사진은 기존에 확보한 프로젝트 자료를 재사용했다. 시안에서 화면 비율에 맞춘 표시 크롭을 포함하며 원본 파일은 변경하지 않았다. 십장생굴뚝은 하단 기관 표기를 포함한 전체 사진을 표시했다.
