# 프로토타입 콘텐츠 원본

P01 보완 자료는 [별도 준비 묶음](../content-preparation/README.md)에 있다. 비교 사진 3장·새 대상 2개·추가 질문 4개·경회루→수정전 연결을 검수했다. 현재 v1 앱이 이 자료를 읽는 것은 아니다. P02/P06 통합 전에는 아래 `content.json`을 준비 묶음으로 교체하지 않는다.

이 폴더는 앱이 사용하는 실제 콘텐츠 원본이다. [모바일 웹](../../../prototype/README.md)의 Vite `publicDir`에서 직접 제공하며 빌드 때 자동 복사한다. 원본을 중복 관리하지 않고 출처 필드를 함께 보존한다.

## 먼저 확인할 자료

- [content.json](content.json): C01~C03 장면, 대상 5개, 설명 7개, 관련 질문 2개, 사실별 출처와 사진 3개의 provenance.
- [경회루 사진](assets/gyeonghoeru.jpg): 궁능유적본부 제공, 2000×1499px. 연못과 누각 전체가 보이는 높은 시점의 사진이다. 실제 방문자의 눈높이를 재현한 자료로 해석하지 않는다.
- [근정전 사진](assets/geunjeongjeon.jpg): 궁능유적본부 제공, 2000×1151px. 정면 건물과 앞마당의 돌 표식이 보인다. 부분 선택 영역과 모바일 판독성은 P06에서 확인한다.
- [자경전 십장생굴뚝 사진](assets/ten-longevity-chimney.webp): 한국민족문화대백과사전 미디어 `7b8dca9e`, 1200×1194px. 응답의 실제 형식인 WebP로 저장했고 하단 기관 표기를 보존했다.

세 사진 모두 원본 바이트를 저장했다. 크롭·색상 보정·생성형 확대·표식 합성을 하지 않았다. 촬영일은 모두 미상이다. 웹 업로드일이나 파일 수정일을 촬영일로 사용하지 않는다.

궁능유적본부 자료는 해당 건물 사진 묶음의 `OPEN BY` 표시(공공누리 제1유형)를 확인했다. JSON의 `licenseEvidenceUrl`은 해당 사진 묶음, `licenseMarkUrl`은 그 묶음이 표시한 유형 표식이다. 한국민족문화대백과사전은 선택한 개별 미디어의 제1유형 표시를 확인했다. 해설과 사진의 출처는 화면에서도 각각 보여준다.

## 검수 범위와 인계

`reviewed`는 AI가 사진의 대상, 설명의 사실, 출처, 개별 재사용 표시를 대조했다는 뜻이다. 사용자의 최종 콘텐츠 확인, 스마트폰 실기기의 판독성, 현장 검증을 대신하지 않는다. 세 장면을 실행 자료로 연결했으며 브라우저 확인과 실기기 검증은 [검증 기록](../../../prototype/VERIFICATION.md)에서 구분한다.

C01은 사진 속 대상을 경회루로 대조했고, 짧은 설명의 연못·연회 용도와 관련 질문의 1867년 재건은 한국민족문화대백과사전의 해당 항목에서 확인했다. 오래된 건물의 기원을 현재 남아 있는 건물의 재건 시기와 구분한다. 해설 원문을 길게 복사하지 않고 짧게 재서술했다.

근정전의 품계석은 사진에서 작아 첫 부분 선택 대상을 앞마당 가운데의 돌바닥으로 정했다. [궁능유적본부 설명](https://royal.khs.go.kr/user/board/E101020000_view_storyBoard.ajax?id=20231123030313006700&siteCode=ENG)의 넓고 얇은 돌, 가운데 세 갈래 길, 품계에 따른 관리 자리 표식을 근거로 삼는다. 거친 표면·배수의 이유를 이 근거만으로 설명하지 않는다. 첫 지원 영역은 사진 아래 가운데이고 인접한 미지원 영역을 남겼다. 같은 바닥의 모든 지점을 지원하는 것은 아니므로 관심 대상과 지원 영역의 불일치를 관찰에서 따로 기록한다.

십장생굴뚝 해설은 [해당 굴뚝 항목](https://encykorea.aks.ac.kr/Article/E0002449)의 굴뚝 구조와 중앙 십장생 문양을 근거로 작성했다. 사진의 중앙 문양과 위쪽 연기 배출구를 별도 대상으로 구분한다. 왕후의 장수를 위해 만들었다는 추정과 상충하는 건축 연도는 답변에서 제외했다. 자경전 건물 사진이 없는 장면은 `wholeTargetId=null`이며 건물 전체 선택을 표시하지 않는다.

## 검사

`prototype/`에서 다음 명령으로 JSON 참조, 검수 표시, 출처 필드, 실제 사진 크기·SHA-256을 확인한다. 검사 스크립트는 Node 표준 모듈만 사용한다.

```powershell
npm.cmd run check:content
```

이미지 영역의 화면 대응과 상호작용 검사는 앱 구현 후 수행한다. 파일 해시 일치는 웹의 향후 이용 조건 변경을 자동 검증한다는 뜻이 아니다. 출처 표기와 재사용 조건의 확인일은 JSON의 `checkedAt`에 남긴다.
