먼저 자유롭게 보기

어떤 앱인지 자유롭게 둘러보세요. 무엇을 먼저 눌렀고, 어떤 느낌이었나요?

S1. 이름 모르는 건물 알아보기

시작 준비: 홈 → 하단 ‘사진으로 찾기’ → ‘연못 앞의 장면’
‘어디가 궁금한가요?’ 화면에서 시작해요.

해볼 일: 사진 속 건물의 이름과 어떤 곳인지 알아보세요.

S2. 궁금한 부분 알아보기

시작 준비: 홈 → ‘사진으로 찾기’ → ‘넓은 앞마당의 장면’
‘어디가 궁금한가요?’ 화면에서 시작해요.

해볼 일: 사진에서 궁금한 부분을 골라 알아보세요.

먼저 자유롭게 골라요. 그 뒤 더 확인하고 싶으면 돌바닥을 골라보고, 다른 부분으로 바꿔 보세요.

S3. 홈에서 관심 가는 것 보기

시작: 홈 — 하단 ‘홈’을 누르세요.

해볼 일: 홈을 둘러보고 관심 가는 것이 있으면 열어보세요. 없으면 넘어가도 돼요.

S4. 닮은 건물 비교하기

시작 준비: 홈 → ‘사진으로 찾기’ → ‘넓은 돌단 위 긴 전각’
‘이 건물은 무엇일까요?’ 화면에서 시작해요.

해볼 일: 사진과 특징을 비교해 어떤 건물인지 골라보세요. 맞는 것이 없다고 생각하면 그렇게 선택해도 돼요.

S5. 설명을 읽은 뒤 이어서 보기

시작: 경회루 기본 설명 화면
여는 순서: 홈 → ‘사진으로 찾기’ → ‘연못 앞의 장면’ → ‘건물 전체 알아보기’

해볼 일: 설명을 읽은 뒤 원하는 다음 행동을 해보세요. 더 보거나, 다른 것을 찾아보거나, 끝내도 괜찮아요.
