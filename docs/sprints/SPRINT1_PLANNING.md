## 2. Sprint Goal

> 첫 적용 사례인 경복궁에서 방문객이 지원 장소를 알아보고 자신의 시선을 기록한 뒤, 같은 장소의 다른 사람 흔적을 만나며 관심에 따라 관람을 이어갈 수 있다.

장소 탐색·기록·공유 서비스의 첫 적용 범위는 근정전·교태전·광화문 3곳이다. 다른 장소는 자료를 준비하고 인식을 검증한 뒤 확대한다.

## 4. SP vs Capacity 검증

| 항목 | 내용 |
| --- | --- |
| ① 선택 SP 합계 | 50 SP |
| ② 팀 velocity 가정 | 약 0.94h/SP (Task 47h 기준 환산, 실측 전) |
| ③ 추정 공수 (① × ②) | 47h (Story별 작업 37h + 공통 작업 10h) |
| ④ 팀 Capacity (§1.1) | 60h (평일 3h·주말 5h) |
| ⑤ 버퍼 (④ - ③) | 13h / 약 21.7% |
| ⑥ 판정 | 초기 추정 · 연동 확인 후 잔여 작업 재점검 |

후순위 2개 항목의 작업 4h를 제외해 예비 13h를 확보한다. 권장 비율보다 큰 예비는 행사와 인식·공유 연동 변동에 대비한다.
