상태: 사용자는 기본 탐색과 흔적 경험을 Sprint 1 안에 끝내기 위해 일정 조정을 요청했다. 아래는 그 목표를 반영한 실행 제안이다. 지원 장소, 공유 백엔드, 화면 배치, 시간 배분은 검토안이며 구현 완료나 납기 보장이 아니다. 진행 상태를 중복 관리하는 TODO가 아니라 범위 변경·일정 산정 근거다. 실행 증거는 관련 Issue/PR에서 관리한다.

## 1. 종료 목표와 범위

2026-11-04 기록 방식 변경: [최신 기록 규칙](../DESIGN.md#자유-텍스트-기록과-사진-보관)에 따라 아래 개인 사진을 보관하는 기록 계획은 공통 장소 화면에 연결된 자유 텍스트 기록으로 대체한다. 사진 보관을 제공하면 사용자가 선택해 기기 갤러리에 저장한다. 아래 사진 기록 요구·추정은 이전 계획이며 상세 범위와 추정 영향은 후속 검토 대상이다.

2026-11-04 후속 결정: [공개 이야기의 열람 경계](../DESIGN.md#방문자-이야기의-탐색과-공개)가 이 문서의 기록 선행 제한을 대체한다. 공개 이야기는 메인에서도 내 기록 없이 전체 열람할 수 있으며, 기록 후에는 같은 장소의 이야기로 이어진다. 아래 §5의 4번과 6번에 있는 기록 선행 제한·미채택 표기는 이전 검토안이다. 메인 탐색 추가에 따른 일정·추정은 아직 재산정하지 않았다.

11/16 Review에서 Android 실기기로 다음 흐름을 재현하고 사용자 관찰 결과와 한계를 설명한다.

> 지원 장소를 사진·이름·현재 위치로 찾고 출처 있는 설명을 확인한다. 자기 사진과 감상을 비공개로 기록한 뒤 같은 장소의 다른 시선을 열어보고, 원하면 자기 기록을 공유하거나 관련 내용을 더 알아본다.

일정 산정은 **2~3개 장소의 제한된 참여자 시험판**, 서로 다른 두 기기의 실제 텍스트 공유까지를 목표로 가정한다. 준비된 글만 보여주는 버전은 중간 산출물이며 실제 공유 완료가 아니다. 사진 인식·GPS는 기록의 진실성이나 현장 방문을 보증하는 수단이 아니다.

## 2. 가용 시간

- 수업 일정은 10/26~11/16 그대로 유지한다. 11/16은 Review/시연으로 개발 시간에서 제외한다.
- 기존 75시간은 10/26~11/15 전체에 대한 계획값이지 현재 잔여 시간이 아니다.
- 10/29~11/15: 평일 12일 × 3시간 + 주말 6일 × 5시간 = **66시간**.
- 10/29의 3시간을 전부 쓸 수 있다는 가정이다. 오늘 시간이 이미 소진됐다면 63시간 이하로 낮춘다. 지난 3일의 작업량·소요 시간은 추정해서 채우지 않는다.
- **계획 작업 56시간 + 예비 10시간**을 배분한다. 이는 작업별 실측 추정이나 velocity가 아닌 투자 상한 초안이다. 특히 모델 자료·학습과 네이티브 연결이 이 안에 끝난다는 근거는 아직 없다.
- AI 도움을 별도 인원·추가 가용 시간으로 계산하지 않는다. 준비·콘텐츠·빌드·시험·기록도 이 시간에 포함한다.

## 5. 완료 확인과 가치 검증

다음은 이 시험판의 제안된 완료 조건이다. 제품 전체 성능 목표 달성·일반 사용자 수요 입증과는 별개다.

1. 지정 Android 기기·설치 빌드에서 실제 입력과 위치 흐름을 실행하고 기기/OS/앱/모델 버전을 기록한다. 거부·오차·범위 밖 입력에서도 사용할 수 있는 경로가 있다.
2. 실제 사진 평가의 건물별·조건별 결과와 오인식/판단 보류를 기록한다. 학습/개발/평가 자료를 분리하며, 평가 세트·판정 기준은 실행 전에 확정한다. 작은 시연 성공으로 기존 Top-1/Top-3 목표 달성을 주장하지 않는다.
3. 사용자 A의 비공개 기록은 B에게 노출되지 않는다. A가 공개한 글만 B의 동일 장소에서 보이고, 다른 사용자가 A의 글을 수정/삭제할 수 없다. A의 삭제·관리자 숨김은 이후 조회에서 반영된다.
4. 기록 전 다른 글이 의도치 않게 보이지 않고, 사진/메모 저장 실패 시 입력이 사라지지 않는다. 글 공개 없이도 본인 기록 후 열람이 가능하다. 이것은 UX 순서이며 검증된 현장 방문 인증이 아니다.
5. 기본 설명·검색은 잠기지 않고, 공식 사실·참여자 감상·제작 예시는 구분된다. 실제 참여자의 글은 시험 사용 동의를 확보한다.
6. 같은 글을 일반 목록과 장소에 연결한 방식으로 보여주는 소규모 비교를 준비한다. 노출 순서/장소를 교차해 반복 읽기 영향을 기록한다. ‘먼저 기록’과 ‘기록 권장·건너뛰기’는 비교할 설계안이며 후자를 몰래 기본값으로 바꾸지 않는다.
7. 자발적 다음 열람, 달라진 시선의 구체적인 설명, 기록 부담·이탈, 공개 여부를 구분해 기록한다. 글만 읽고 여운을 느끼는 경험도 가치 후보다. 이동·촬영·체류 시간 증가를 단독 성공 지표로 쓰지 않는다.

참여자 모집·가능한 현장 날짜는 초반부터 확보한다. 현장 참여가 없으면 사진 기반 모의 관찰로 표시하고 GPS 현장 신뢰성·실제 관람 효과를 미검증으로 남긴다. 소수 관찰의 수치로 시장성을 판정하지 않는다.

## 6. 다음 작업과 기록 경계

첫 작업은 **실제 Android 시험 기기 지정 → 설치 빌드와 작은 인식 호출 검증 → 흔적 흐름 화면/공유 계약 확정**이다. 기기 모델·OS, 시험 참여 일정, 관리형 공유 서비스 선택은 아직 필요하다. 세부 화면 변경은 기존 사용자 검토 원칙을 따른다.

이 문서는 새 일정의 검토본이다. 기존 Word Planning 1차 초안은 과거 기준으로 보존하고, 상세 추정/범위 합의 후 개정한다. 2026-10-29 GitHub CLI 조회는 HTTP 401로 실패하여 최신 원격 Issue를 확인하지 못했다. 이슈 생성·갱신, 커밋·푸시·Wiki 게시를 수행했다고 보고하지 않는다. 인증 회복 후 기존 관련 Issue에 통합할 수 있는지 먼저 확인하며 프로토타입 종료 Issue를 신규 제품 작업의 통으로 재사용하지 않는다.
