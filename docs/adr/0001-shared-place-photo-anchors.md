# ADR 0001 — 쪽지는 공통 장소 사진에 고정한다

- 날짜: 2026-11-04 (KST)
- 상태: 채택 — 첫 버전의 설계 결정. 임의 사진 간 보정과 실제 사용자 간 공유의 구현·검증을 의미하지 않는다.
- 적용 범위: 장소 인식 이후의 쪽지 작성·열람 및 위치 저장.

## 대화와 결정 배경

사용자는 같은 장소에서 다른 사람이 남긴 쪽지를 사진 속에서 발견하는 경험을 원했다. 근정전 시안은 한 장의 사진 위에 위치가 다른 흔적을 배치했다. 작성 흐름을 논의하면서 사용자가 질문했다. **A와 B가 같은 장소를 각자 다른 위치·각도에서 촬영하면, A가 남긴 쪽지를 B의 사진 어디에 보여주는가?**

공통 사진을 쓰는 안과 각자의 사진에 쪽지를 옮기는 안을 비교했다. 사용자는 후자의 경우 각 촬영에서 어디를 바라봤고 무엇이 보이는지, 양쪽 사진에서 같은 지점이 어디인지 알아낸 뒤 쪽지를 다시 매핑해야 한다고 짚었다. 임의 시점의 보정은 첫 버전에 과하다고 판단했다. 첫 버전에서 확인할 가치는 **같은 장소에서 다른 사람의 흔적을 발견하는 경험**이다. 이 경험을 확인하기 위해 개인 촬영 사진 위의 정합까지 선행할 필요는 없다.

## 결정

**촬영 사진은 장소를 찾는 입력으로 사용한다. 쪽지는 앱의 공통 장소 사진 위에서 위치를 선택해 남기고, 같은 공통 사진에서 읽는다.** 첫 버전은 장소마다 검수된 공통 장면 하나로 시작한다. 장소를 직접 선택해도 같은 장면으로 들어갈 수 있다.

- 입력: 인식하거나 직접 선택한 `placeId`, 공통 장면에서 누른 지점. 촬영 입력 사진은 쪽지의 배경이나 위치 기준이 아니다.
- 저장: `sceneId`와 해당 원본 구도 기준 정규화 좌표 `u`, `v`(각각 0..1)를 기록한다. `placeId`는 장소를, `sceneId`는 사진의 구도를 식별한다. 개인 사진과 기기 화면 픽셀 좌표는 쪽지 위치를 구성하지 않는다.
- 표시: 해당 `sceneId`의 사진과 쪽지 위치에 동일한 확대·이동 변환을 적용한다. 예를 들어 A가 근정전 공통 사진의 가로 40%, 세로 70%에 남기면, B도 공통 사진의 그 지점에서 본다. 화면 크롭으로 지점이 화면 밖이면 현재 화면에 억지로 옮겨 표시하지 않는다.
- 장면 버전: 같은 원본을 화면 크기에 맞춰 자르는 것은 화면 표시 변환이다. **기준 사진 파일의 구도 자체**를 자르거나 촬영 시점을 바꾸면 새 `sceneId`를 부여한다. 기존 쪽지는 원래 장면에 유지하고 새 장면으로 자동 이전하지 않는다.

## 대안과 기술적 이유

| 대안 | 처리할 변수와 선택 이유 |
| --- | --- |
| **공통 사진에 고정 — 채택** | 두 사람이 동일한 사진 좌표계를 쓴다. 화면 크기·비율·크롭과 장면 버전만 다룬다. 누구의 촬영 시점에도 쪽지가 자동으로 붙지는 않는다. |
| **사진 간 2D 정합 — 후속 실험 후보** | 두 사진에서 같은 특징점을 찾고 변환을 추정한다. 공통으로 보이는 벽면 등 한 평면은 촬영 위치·방향을 명시적으로 복원하지 않고도 맞출 수 있다. 이동하면서 촬영한 사진에서 지붕·기둥·마당처럼 깊이가 다른 지점을 한 평면 변환으로 모두 맞출 수는 없다. 사진에 해당 지점이 가려지거나 프레임 밖인 경우도 처리해야 한다. |
| **실제 공간에 고정 — 첫 버전 제외** | 쪽지의 실제 3D 위치, 카메라의 위치·방향과 투영, 대상의 가시성을 함께 다룬다. GPS로 촬영 지점을 알아도 사진 속 한 점의 깊이나 대응 픽셀이 정해지지 않는다. 기기·현장 조건별 정합 평가와 실패 시 표시 보류가 필요하다. |

장소 인식과 쪽지 좌표를 분리하면 인식 모델이나 촬영 조건이 바뀌어도 이미 남긴 쪽지의 위치는 바뀌지 않는다. 대신 공통 사진에서 보이지 않는 장소의 부분에는 쪽지를 남길 수 없고, 다른 촬영 각도로 넘어가면 동일한 위치에 자동 표시하지 않는다.

## 검증과 재검토 조건

- 현재 근정전 Android 시안은 공통 사진에 개발용 흔적을 표시하고 여닫는 단계까지 검증했다. 두 사용자가 서로 다른 사진으로 같은 장소를 인식하고, 실제로 작성·공개한 쪽지를 같은 위치에서 읽는 흐름은 미검증이다.
- 다음 검증: 서로 다른 촬영 사진으로 같은 장소에 진입해 동일 `sceneId`를 여는지, 다른 화면 크기·크롭에서도 같은 원본 지점에 쪽지가 붙는지 확인한다. 크롭 밖·다른 장면·사진 교체에 대해 잘못된 위치로 옮겨 보이지 않는지도 확인한다.
- 공통 사진 방식이 발견 경험을 충분히 지원하지 않거나, 사용자가 자기 사진에서도 쪽지를 볼 필요를 반복해서 보이면 보정을 재검토한다. 첫 실험은 같은 평면의 제한된 사진 쌍으로 한다. 정합 성공·실패·가려짐을 구분하고, 확신할 수 없으면 공통 장면에서 글을 여는 경로를 제공한다. 목표 오차와 표시 보류 기준은 실험 전에 정한다.
