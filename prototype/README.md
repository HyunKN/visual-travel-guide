# 궁금한 궁 · 자유 탐색 프로토타입

2026-10-17 사용자 검토 후 모바일 배치를 다시 구성했다. **하나의 앱 안에서 홈·검색·사진 탐색·설명을 자유롭게 오간다.** 시나리오는 관찰 과제와 순서이며 앱의 사진·기능·이동을 잠그지 않는다. 이후 제공된 PC R01·스마트폰 R02·환경 미기록 R03의 [세 테스트 결과·백로그 근거](../docs/prototype/OBSERVATION_RESULTS.md)를 정리했다. 모바일 사용 기록 접수와 수정 후 실기기 품질 통과를 구분한다.

## 실행

### Sites 배포 — 2026-10-17

[배포 주소](https://gunggeumhan-gung-prototype-20261017.milkyape4.chatgpt.site/)는 배포 성공을 확인했지만 현재 **소유자 전용**이다. 외부 테스터가 로그인 없이 접속하는 공개 전환은 자동 승인 검토에서 거절되어 명시적 사용자 승인 대기다. 로그인 화면까지 확인했으며 배포 주소에서 앱 내부 동작은 아직 검증하지 못했다.

Vite 빌드 결과만 별도 Sites 저장소에 올렸다. 테스트지·참여자 기록·개발 문서는 배포하지 않았다. 동일 Site ID는 `appgprj_6ad27feee57c8191b12aa8a95c44b10e`이며, 이후 배포도 이 Site를 재사용한다. 자세한 배포·검증 상태는 [검증 기록](VERIFICATION.md)을 따른다.

### 로컬 실행

확인한 환경: Windows·Node24.11.1/npm11.6.2/Vite8.3.4. Node22.12 이상을 사용한다. 저장소 루트에서:

```powershell
cd prototype
npm.cmd ci
npm.cmd run dev
```

기본 개발 주소는 `http://127.0.0.1:5173/`다. 이미 사용 중이면 `npm.cmd run dev -- --port 5174`로 별도 실행한다. 다른 서버를 임의 종료하지 않는다. Windows PowerShell 실행 정책 충돌을 피하려고 `npm.cmd`를 쓴다.

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

preview는 `http://127.0.0.1:4173/`에서 현재 `dist/`를 제공한다. 필요 시 `-- --port 4174`를 붙인다. 종료는 해당 터미널 Ctrl+C다. `index.html` 직접 열기는 지원하지 않는다. `dist/`는 생성물로 커밋하지 않는다.

## 현재 사용할 수 있는 흐름

- 홈 상단 검색창: 건물 이름·문양·바닥 등으로 확보한7대상의 이름·설명·준비된 질문을 검색한다. 결과를 누르면 대상의 참고 사진·기본 설명을 연다. 결과 없음은 임의 답변 대신 사진 탐색 대안을 제공한다.
- 사진으로 찾기: 모든6장면을 자유롭게 고른다. 전체 건물·부분 선택·미리보기·확인 또는 해당 사진에 연결된 후보 비교로 진행한다. 자동 촬영·업로드·인식은 없다.
- 후보 비교: ‘넓은 돌단 위 긴 전각’ 입력에서 준비된 두 후보를 비교한다. 어디서 출발했든 접근하며 재비교·해당 없음·사진 다시 보기를 제공한다. 오답 자동 교정·확률·가짜 분석 대기는 없다.
- 설명: 출처·더 읽기·관련 질문을 선택적으로 살핀다. 부분 지원 사진에서 재선택하고, 다른 대상 탐색 또는 검수된 다음 관람 제안으로 이어갈 수 있다.
- 이동: 상단 뒤로가기·검색, 공통 하단 홈/검색/사진 탐색을 제공한다. 뒤로는 직전 검색어·결과·스크롤·가능한 원래 조작부 포커스를 복원한다. 앱 내부 이력이 없는 진입은 홈으로 연결한다. 홈은 같은 실행이며 새로고침은 새 실행이다.

홈 호기심 카드는 작은 88px 사진·짧은 문구의 보조 경로다. 주 탐색80:보조20은 시각 위계 목표이며 확대 글자를 자르는 고정 비율이 아니다. 하단 조작부 높이를 실제 측정해 본문 아래 공간을 확보한다.

촬영·인식·GPS·지도·자유 질문/LLM·계정·DB·관찰 로그 수집은 없다. 로컬 문자열 검색을 전체 경복궁 검색이나 AI 성능으로 해석하지 않는다.

## 디자인·폰트·재질

흰 바탕·먹청색·작은 주홍 포인트를 사용한다. 홈 메뉴에서 사진형과 직접 제작한 3D 궁궐 이야기를 고른다. 같은 검색·이동·자료를 공유한다. 3D는 실제 조사·복원 모형이 아니며 해당 홈에서만 Three.js0.186.1을 동적 import한다.

사용자 지정 서체는 **Spoqa Han Sans 원래 family**다. Regular400/Bold700의 공식 WOFF2를 자체 제공하며 Neo로 바꾸지 않았다. [다운로드 출처·고정 커밋·해시](src/fonts/SOURCE.txt)와 [OFL1.1·저작권 고지](src/fonts/LICENSE.txt)를 보관하고 앱 메뉴에서 배포된 라이선스를 연다. 네트워크 CDN 폰트에 의존하지 않는다.

[재질 비교](http://127.0.0.1:4173/materials.html)와 앱은 같은 CSS+SVG 벡터 필터를 사용한다. 볼록 곡면 띠14px·중앙 중립·테두리 하이라이트를 유지하며 최대 각 축 변위를5→7px(scale14)로 높였다. 유리는 Canvas를 사용하지 않는다. 사진형 홈 Canvas는 없고 선택적 3D 렌더는 별도다. Chromium 이외·접근성 재질 대체는 기본 재질을 사용한다. 네이티브 Liquid Glass·모바일 성능 통과를 뜻하지 않는다.

**탄성 표현 수정은 사용자 요청으로 후속 보완에 남긴다.** 이번에 spring·motion 코드는 바꾸지 않았다. 기존 움직임 설정은 기기의 reduced-motion을 따르며 탭의 명시 설정만 sessionStorage에 보관한다. 사용 이력은 저장하지 않는다.

## 관찰 안내와 별도 리허설

사용자가 읽고 작성할 문서는 [HTML 테스트 안내·기록](../docs/prototype/TEST_GUIDE.html)이다. 앱 안의 준비된 사진을 사용해 같은 앱에서 S1~S5를 관찰한다. 외부 큰 화면·인쇄 사진을 준비하는 절차는 사용하지 않는다. 버튼 순서·정답을 먼저 가르치지 않으며 다른 경로·사전 노출·관심 없음·종료도 기록한다. 제작자 리허설과 첫 사용 관찰은 분리한다. 실제 R01·R02·R03 분석은 위 결과 문서를 따른다.

기존 `?preset=S1`~`S5` URL은 시작 맥락 호환용이며 기능을 잠그지 않는다. 홈 호기심 카드는 공통으로 제공한다. `#test`는 별도 개발 리허설(글자200%·사진/답변/출처 누락·불투명 재질)에만 사용한다. 보통 관찰은 이 설정 없이 시작한다. 사진 실패 재시도는 고정 실패를 성공으로 꾸미지 않으며 텍스트 선택 경로를 제공한다.

R02의 실제 스마트폰 사용 기록과 제작자 보충 화면을 접수했으며, 확대 조작·하단 영역 관련 문제를 정리했다. 실기기 품질 통과나 수정 완료는 아직 확인하지 않았다. 같은 신뢰하는 LAN에서 필요할 때만 `npm.cmd run preview:lan`을 선택적으로 실행한다. 기본 서버는 loopback이다. LAN 바인딩·방화벽 변경은 수행하지 않았다. Sites의 접근 상태는 위 배포 기록을 따르며 이번 관찰 정리에서 다시 조회하거나 변경하지 않았다. [실행·관찰 절차](../docs/prototype/OBSERVATION_RUNBOOK.md), [검증 기록](VERIFICATION.md)에서 제작자 검사와 참여자 보고·보충 설명을 구분한다.

## 자료와 코드 읽기

자료는 `2026-10-16-scenes.3` / schemaVersion2, 6장면·7대상·13답변·6질문·6사진·10출처다. Vite `publicDir`은 `docs/prototype/content`이며 복사본을 수동 수정하지 않는다. 새 사진3장은 긴 변1600px WebP 파생본이고 원본은 P01 준비 폴더에 보존한다. `build`는 원본/파생 해시·크기를 함께 검사한다. 사진 생성형 수정은 없다. 촬영일은 미상이다.

1. [content.json](../docs/prototype/content/content.json), [content.js](src/content.js): 자료·출처·좌표·답변 연결 검증.
2. [browse.js](src/browse.js): 전체 탐색 목록, 검수된 로컬 검색. 과거 preset 입력을 변경하지 않는다.
3. [state.js](src/state.js): H/S/N/V/C/A/Q/E와 대상·질문·검색어·탐색 맥락 전환·복원 검증.
4. [main.js](src/main.js): 화면·검색 입력·시간순 history·포커스·오류 복구.
5. [browse.css](src/browse.css): 현재 모바일 배치·서체·검색·작은 호기심 카드. [glass-map.js](src/glass-map.js)·[glass-optics.js](src/glass-optics.js)·[glass.css](src/glass.css): 공유 굴절.

실행 준비·기능 검사·사람의 궁금증 해소는 서로 다른 상태다. 실제 관찰 결과는 기존 [P08 Issue](https://github.com/HyunKN/visual-travel-guide/issues/13)에 모은다.
