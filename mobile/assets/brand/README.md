# 궁 로고

`palace.svg`는 프로토타입의 두 지붕·세 홍예문 모티프를 실제 공통 사진 `mobile/assets/places/gwanghwamun.jpg`의 폭·처마·중앙 홍예 비례를 참고해 다시 그린 앱용 벡터다. 공식 문화유산 로고가 아니다.

2026-11-07 사용자가 제공한 색 견본에서 지붕 먹색 #212320, 단청 녹색 #01865B/#0A9C4B, 목재 #83352B와 선 #C73F2F, 석축 #FBFAF6, 현판의 작은 금색 #F4BB2E를 골랐다. 견본 전체를 좁은 심벌에 같은 비율로 넣지 않는다. 로고 배색 결정으로, 앱 본문·행동 색은 중립 먹색/회색을 유지한다.

`palace.png`는 Android Image용 320×224 투명 래스터다. 로컬 PyMuPDF로 위 SVG를 렌더했다.
